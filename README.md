# REYES — Infrastructure Portfolio

Static, framework-free portfolio designed for GitHub Pages or Cloudflare Pages.

## What is included

- Responsive dark/light interface
- Real inline SVG icons with no external icon CDN
- Interactive Pickford Homelab architecture
- Clickable technology toolkit
- Case-study dialogs
- Image gallery lightbox
- Mobile navigation
- Keyboard-accessible controls and reduced-motion support
- Local images and no external font dependency
- Public-safe wording that avoids internal addresses and credentials

## Publish with GitHub Pages

1. Copy these files to the root of your portfolio repository.
2. Commit and push to the branch GitHub Pages uses (usually `main`).
3. In GitHub: **Settings → Pages → Build and deployment → Deploy from a branch**.
4. Select the branch and `/ (root)` folder, then save.

## Customize

Update these two public links in `index.html` if needed:

- GitHub: `https://github.com/ficoreyes`
- Email: `info@ficoreyes.com`

The architecture is intentionally abstracted. Do not publish internal IP addresses, credentials, tunnel IDs, tokens, or administrative URLs.
